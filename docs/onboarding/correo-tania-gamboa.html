2. Configuración en Outlook (Windows o Mac)

  1. Abre Outlook → menú Archivo → Información → Agregar cuenta
  2. Elige "Configurar manualmente las opciones del servidor o tipos de servidor adicionales" → Siguiente
  3. Selecciona POP o IMAP → Siguiente
  4. En Información del servidor:
    • Tipo de cuenta: IMAP
    • Servidor de entrada: mail.convergencia.pro
    • Servidor de salida: mail.convergencia.pro
  5. En Información de inicio de sesión:
    • Usuario: tania.gamboa@convergencia.pro
    • Contraseña: la de arriba
  6. Click Más configuraciones… → pestaña Servidor de salida:
    • Marca "Mi servidor de salida (SMTP) requiere autenticación"
    • Marca "Usar la misma configuración que mi servidor de entrada"
  7. Pestaña Avanzadas:
    • Servidor de entrada (IMAP): 993 / tipo de conexión cifrada: SSL/TLS
    • Servidor de salida (SMTP): 465 / tipo de conexión cifrada: SSL/TLS
  8. Siguiente → "Probar configuración de la cuenta" → debe dar todo OK con tildes verdes → Cerrar → Siguiente → Finalizar

4. Instalar tu firma personalizada

Tu firma está diseñada con la línea editorial de Convergencia. Está adjunta a este email como archivo firma-tania-gamboa.html.

Outlook:

  1. Abre el archivo adjunto firma-tania-gamboa.html en el navegador (doble click)
  2. En Outlook: Archivo → Opciones → Correo → Firmas…
  3. Click Nueva → ponle de nombre "Convergencia" → en el editor, click derecho → Ver código fuente (o pega con Ctrl+V directamente si ya copiaste el HTML)
  4. Copia TODO el contenido del archivo HTML (Ctrl+A, Ctrl+C) y pégalo en el editor de firma
  5. En "Elija la firma predeterminada", selecciona "Convergencia" para mensajes nuevos y respuestas → Aceptar

Thunderbird:

  1. Abre Configuración de la cuenta (☰ → Configuración o el ícono de engranaje)
  2. Bajo tu cuenta, click "Manage Identities" → click en tu identidad
  3. Marca "Use HTML" y pega el contenido del archivo HTML en el cuadro de firma
  4. Aceptar → cerrar
